Creates a Stateless or Stateful Flutter widget backed by a Flutter Designer model. Stateful forms include a separate State class for user state and event handlers; choosing Stateful does not add value bindings automatically. The Dart source is created only in lib or one of its subfolders. Its relative path is mirrored below .fd_templates; for example, lib/screens/home.dart is paired with .fd_templates/screens/home.fd.
